# 更新日志

## 1.1.1（未发布）

1. 校园卡余额卡片样式与牛×5 保持一致
2. 修复校园卡余额刷新失败的问题
3. 首次获取失败时会自动重试一次

## 1.1.0（已发布）

1. 「我」页顶部新增校园卡余额卡片，显示姓名、卡号与余额
2. 点击卡片可手动刷新；网络异常时保留上次余额并提示重试
3. 退出登录会清除余额缓存，切换账号不会串数据

## 1.0.9（已发布）

1. 「我」页面保持空白，头像、设置与退出登录移入右上角设置图标
2. 原「我」页面内容改为二级页面，从设置图标进入

## 1.0.8（已发布）

1. 课表页移除顶部导航栏与「课表」标题，内容直接从状态栏下方开始
2. 周视图的月份与星期表头固定，上下滚动课程时不再跟着移动

## 1.0.7（已发布）

1. 退出登录会清除本地课表与登录状态，切换账号不再显示上一个人的课表
2. 课表同步入口移到「我的 → 设置 → 课表同步」，课表页更简洁
3. 登录后本地没有课表时自动同步；失败可在首页一键重新同步
4. 同步失败时提示检查「智慧湘农-教务系统」能否正常进入

## 1.0.6（已发布）

1. 修复课表同步一直提示「身份验证超时」的问题：改用与牛×5 一致的认证方式，并在页面请求中直接捕获 Token
2. 同步时不再弹出「正在验证教务身份」弹窗，改为页面内进度提示
3. 优化 Cookie 注入范围，首次同步成功率更高

## 1.0.5（已发布）

1. 首页改为课表：打开软件直接看到本周课程，左右滑动切换周，左侧显示当月月份
2. 教务课表一键同步：登录后在课表右上角点刷新，自动拉取本学期全部课程；首次同步会验证教务身份
3. 课程详情与自定义颜色：点击课程查看时间、地点、教师，可单独修改颜色
4. 同步失败会给出原因并保留原课表，不会清空本地数据
5. 移除场馆预约，底部导航调整为「课表 / 我的」
