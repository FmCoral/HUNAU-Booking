# 发布与更新

> 本文只描述方案与约定。R2 桶、GitHub 仓库、DNS 记录均待用户创建后落地。

## 1. 域名

| 项 | 值 |
| --- | --- |
| 更新域名 | `apk.book.hunau.fmcoral.com` |
| 用途 | 版本检查 `version.json` + APK 分发 |
| 形态 | Cloudflare R2 公共桶 + 自定义域名绑定 |

与现有 `apk.hunau.fmcoral.com` 保持同一套模式，避免依赖 GitHub API（国内访问不稳定）。

## 2. R2 桶约定

| 项 | 约定 |
| --- | --- |
| 桶名（建议） | `book-apk` |
| 访问权限 | 公共读，不开放写 |
| 目录结构 | `latest/`、`v{version}/` |

```
book-apk/
├── latest/
│   ├── version.json
│   └── app-release.apk
└── v1.0.0/
    └── app_v1.0.0.apk
```

## 3. version.json 结构

```json
{
  "version": "1.0.0",
  "buildNumber": 1,
  "minVersion": "1.0.0",
  "downloadUrl": "https://apk.book.hunau.fmcoral.com/latest/app_v1.0.0.apk",
  "changelog": "首个版本",
  "force": false,
  "publishedAt": "2026-11-07T12:00:00Z"
}
```

字段说明：

| 字段 | 说明 |
| --- | --- |
| version | 版本名，对应 pubspec 的 version 前半部分 |
| buildNumber | 版本号，对应 `+` 后的数字 |
| minVersion | 低于该版本强制更新 |
| downloadUrl | 实际下载地址 |
| changelog | 更新日志 |
| force | 是否强制更新 |
| publishedAt | 发布时间 |

## 4. 客户端检测流程

```
启动 → GET /latest/version.json（超时 5s）
     → 读取本地 version + buildNumber
     → 若服务端 buildNumber 更大：提示更新
     → force 或本地低于 minVersion：强制更新
     → 用户确认后下载 APK 并唤起安装
```

- 检测失败静默处理，不阻塞启动。
- 不请求 GitHub API。

## 5. Cloudflare 配置

- R2 桶绑定自定义域名 `apk.book.hunau.fmcoral.com`。
- 缓存规则：
  - `latest/version.json`：缓存 1 分钟
  - `*.apk`：缓存 5 分钟
- 公开访问，无需鉴权。

## 6. GitHub Actions（待仓库创建后补）

触发方式：推送 `v*` tag。

流程：

1. 检出代码，安装 Flutter。
2. 构建前清理磁盘（runner 空间有限）。
3. 设置签名：从 Secrets 注入 keystore 与 `key.properties`。
4. 构建：`flutter build apk --release --split-per-abi`。
5. 重命名产物为 `app_v{version}.apk`。
6. 上传到 R2：`v{version}/` 与 `latest/`。
7. 生成并上传 `latest/version.json`。
8. 校验远端可访问后结束。

所需 Secrets：

| 名称 | 用途 |
| --- | --- |
| `R2_ACCESS_KEY_ID` | R2 访问密钥 |
| `R2_SECRET_ACCESS_KEY` | R2 密钥 |
| `R2_ENDPOINT` | R2 S3 端点 |
| `R2_BUCKET` | 桶名 |
| `ANDROID_KEYSTORE_BASE64` | 签名文件 |
| `ANDROID_KEY_PROPERTIES` | 签名配置 |

## 7. 本地构建

```powershell
$env:JAVA_HOME="D:\dev\jdk17"
$env:ANDROID_HOME="D:\dev\android-sdk"
& "D:\dev\flutter\bin\flutter.bat" build apk --release --split-per-abi
```

产物：`build/app/outputs/flutter-apk/app-release.apk`（按 ABI 拆分时会有 arm64 等变体）。
